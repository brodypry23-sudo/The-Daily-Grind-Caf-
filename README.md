# Local Café website
Three-page site (Home, Menu, Contact) built with HTML5, CSS3 and Bootstrap 5.3.3 (CDN, needs internet).
Colours: primary #EEF2EC, complementary #1F3D36, branding #E9A820. Fonts: Fraunces + DM Sans (Google Fonts).
Address, phone, email, menu items and photos are placeholders - replace with the client's real details.
